# 景行语文产品需求说明书

版本 v0.8 · 2026-11-23 · 规划稿（含逻辑与思辨 / 议论文支撑）

## 1. 产品目标

景行语文是面向小学一年级至高中三年级学生的独立考试向学习 App。学生按年级做专项题、读课内和课外文章与中文电子书、整理错题、记背知识、学习作文写法并完成写作和修改，并可在阅读中请数字人朗读、提示和提问（中文书伴读）；中高年级增加 **逻辑与思辨** 训练，为议论文的立论、论证与反驳打底。学习结果应能回到下一次练习或复习。

- **主要用户**：有课内巩固和考试备考需求的学生。低年级优先支持短任务、朗读和听写，中高年级逐步增加阅读分析、文言文、逻辑思辨和主观题自评。写作从低年级看图说话和写句子起步，过渡到记叙/说明习作，再进入议论文与考场作文。
- **首批内容假设**：用七年级打通完整学习流程，其余年级继续提供已有内容，按题包和读物审核进度逐步扩充。无对应内容时展示覆盖状态，跨年级浏览由学生主动选择。
- **导航建议**：一级入口为「首页、刷题、阅读、复习、我的」。阅读下分「课内、课外、书架（电子书）」，复习下设「今日复习、错题本」，诗文默写和字词听写由首页、对应专项及复习任务进入，「作文」从首页及刷题页进入，数字人从正在读的篇目/电子书章节进入。首页优先显示继续学习和到期任务。

## 2. 核心学习流程

1. 首启选择年级，首页显示本年级可用的专项、读物及今日复习。改年级后更新默认推荐与复习范围，原年级记录保留。
2. 学生按知识点做题，也可读完一篇文章后做关联题。中断时保留进度和草稿，重新打开可续做。
3. 交卷后查看答案、解析和错题。阅读题解析可定位原文证据。错题可原题订正，具备明确知识点的错题可关联记背卡。
4. 今日复习呈现到期的知识卡和待重做的错题，分别记录记忆评分与作答结果。学生可回到原题或原文。
5. 阅读课内/课外短篇或中文电子书时，可按段或按章呼出数字人伴读（示范朗读、提示、依据原文提问）。结束后回到原阅读位置，可收藏词句、写入素材本或开始理解练习。

6. 学生学习一项写作技巧，完成片段练习或整篇作文，提交后查看有原文依据的批改建议，修改并对照前后版本。议论文路径可先完成逻辑/思辨微练（找论点、补论据、识别漏洞、写一句反驳），再进入提纲与成文。

## 3. 功能需求

| 功能 | 首个可交付版本 | 验收条件 |
| --- | --- | --- |
| K12 语文刷题 | 年级筛选、按知识点组题、题组共用材料、交卷解析。首批覆盖字词基础和现代文阅读，支持单选与有明确答案规则的填空 | 七年级可完成两类专项各一组。退出后恢复草稿，重复提交同一次会话只生成一份结果。填空按该题配置的等价答案和规范判定 |
| 课内语文阅读 | 年级、册次、单元目录；教材按需打开；在具备相应使用权限的文本上提供段落定位、查字词、书签和关联练习 | 能根据所选年级打开课文目录。可在应用内阅读的篇目支持续读与原文定位，只有外链的篇目仍可打开来源，应用内阅读进度以可记录的内容为准 |
| 课外阅读 | 按年级、体裁选审核通过的短篇；支持书架、阅读进度、摘录与篇后理解题 | 学生可从中文书库打开一篇文章、保存进度并恢复。摘录保留出处。关联题能从解析跳回对应段落 |
| 中文电子书阅读器 | 复用阅读器底座，面向中文长篇：导入与打开 `.txt` / `.epub`（及阅读器已支持的 `.md` / `.pdf` 等）；中文书架、目录/章节跳转、续读进度、字号与夜间/宣纸主题、划词查新华、书签与摘录；弱化英语 CEFR 在线书库为默认入口 | 可导入一本中文 EPUB 或 TXT，在应用内翻到指定章节、杀进程后恢复进度与书签。划词可查字。摘录带书名、章节与定位，可进素材本。正式包不内置受版权限制的整书正文 |

| 错题整理 | 自动收录判错题，按年级、来源、知识点、订正状态筛选。记录错因、查看原解析、隐藏答案重做。主观题后续可由学生标记加入 | 同题同版本多次答错只保留一条错题条目并累积作答记录。重做通过后标记已订正，再答错重新进入待订正 |
| 知识记背 | 保留古诗文默写、字词听写与逐字反馈，新增可从解析或阅读收藏的知识卡，沿用 FSRS 排到期日 | 同一知识卡从多个入口添加时可合并来源。完成评分后更新下次复习日期，切换年级后默认队列随之切换且历史可查 |
| 数字人伴读（短篇/课文） | 从授权短篇或可伴读课文的当前段落进入；与「中文书伴读」共用会话与 TTS 链路，上下文模型支持短篇段落与电子书章节两种定位 | 同中文书伴读验收，定位键为篇目+段落；教材仅在具备伴读授权的文本上开放 |
| 作文训练 | 按年级、文体和训练目标选题，支持片段练习及整篇作文。七年级先做记叙文；**八～九年级起开放议论文**（可与逻辑思辨微练串联）。提供题意拆解、选材/论点提纲、草稿自动保存与修改稿 | 记叙：可完成一次片段与一篇整文。议论文：可从思辨微练进入「论点—论据—论证」提纲再成文；中断后恢复草稿，修改稿与历史反馈可查 |
| 作文技巧教学 | 记叙：审题立意、选材、结构、细节与语言。议论文：审题立论、论点提炼、论据选用、论证方法（举例/对比/因果等）、结构（总分/层进/驳论）、辩证与结尾升华。短课含示例拆解、修改对照及随堂练 | 学生能从技巧短课进入对应练习，也能从批改建议回到相关短课；议论文短课可跳转逻辑思辨专项中的同类技能点 |
| 作文批改 | 依据题目要求、年级和文体量规反馈。记叙：切题、内容、结构、语言。议论文：另评论点清晰度、论据适切、论证严密、反驳/辩证是否到位，标注相关原文 | 各建议能关联原句、段落或全文。议论文批改至少能指出「缺论据 / 跳步 / 以偏概全」一类问题中的一种（有文本依据时）。量规版本与文体绑定 |
| 逻辑与思辨 | 独立微练 + 阅读/伴读穿插：识别论点与论据、补全推理链、判断理由是否支持结论、发现常见漏洞（偷换概念、以偏概全、因果不当、人身攻击等）、写一句合理反驳或限定。技能点带 `domain=logic_reasoning`，并映射到议论文技巧课 | 七年级可先做「找观点/给理由」轻量题；八～九年级样本包含识别漏洞与补论据题各至少一组。完成思辨微练后，议论文提纲页能带入本课论点/论据草稿。作答更新逻辑领域分，并可提示「去写一段议论」 |
| 多维能力综合评估 | 按领域（字词、现代文阅读、写作、**逻辑思辨**、文学常识、文言文、诗词等）汇总强弱；阅读过程技能与思辨技能可下钻；综合评估页含雷达、一句话总评、弱项下一步。详见 §8 | 样本足够时能标出强项与弱项并链到练习；逻辑弱时优先推荐思辨微练再推议论文。领域分与题目 `domain` 标签一致 |

### 作文批改与修改

- 作文题保存题干、文体、字数要求、训练目标和量规版本。批改结果关联提交稿与量规版本，修改后重新批改生成独立记录。
- 短文、片段和整篇使用各自适用的量规。反馈先点出可保留的写法，再给出一至三项优先修改建议；针对整篇结构或偏题等问题可标注全文。材料不足时说明无法评估的维度。
- 议论文量规在通用四维之上增加：`claim`（论点）、`evidence`（论据）、`reasoning`（论证）、`rebuttal`（反驳/限定，可选）。批改建议可链回逻辑思辨微练中的同类技能点。
- 学生可逐条查看修改建议、返回原文编辑，并对照两个版本。拍照识别手写作文、教师人工批改和考场限时训练作为后续扩展。

### 逻辑与思辨（服务议论文）

- 技能点示例（写入 `knowledge_point`，`domain=logic_reasoning`）：找论点、区分事实与观点、为结论补一条有效理由、判断理由是否支撑结论、识别常见漏洞、提出反例或限定条件、写一句针对性反驳。
- 呈现形式：短选择题 / 排序题 / 补全一句 / 写一句（有参考或关键词判分规则）。可嵌在现代文议论文阅读篇后题，或独立「思辨 5 分钟」入口。
- 与作文打通：微练产出的「论点草稿」「论据卡片」可一键带入议论文提纲；综合评估中逻辑弱项时，议论文开写前提示先做对应微练（可跳过）。
- 伴读扩展：议论文/评论类读物上，数字人可问「作者的结论是什么？理由充分吗？」并回写 `logic_reasoning` 与 `modern_reading`（若题目指明双标签则双更）。

### 题目、错题与记忆卡

- 题目保存稳定 ID、版本、年级、知识点、题型、材料引用、答案规则、解析、来源与授权信息。阅读材料要有稳定段落 ID。影响判分的修订发布新版本，旧作答仍可说明当时的判分依据。
- 每次作答独立保存。错题本以账号和题目版本归并记录，保存首次和最近错答、累计次数、错因与订正状态。知识卡可链接多个题目或段落，FSRS 独立记录评分和到期日。
- 主观题后续提供参考答案、分点依据和学生自评。数字人可以引导找证据，正式题目答案及评分依据以审核过的题包为准。
- 课堂目录、题库和推荐按年级过滤。阅读进度、草稿、错题及复习记录按账号隔离。离线时已缓存的可用内容仍可阅读与练习，连网后重复同步同一作答或复习事件按稳定 ID 去重。

## 5. 内容与隐私要求

- 正式包的第三方内置语料沿用已归因的 MIT 来源。题目、课外读物、解析及音频上线前记录来源、适用年级、授权用途和审核状态。内容可撤下，已作答记录仍保留；撤下材料按授权条件处理。
- 部编教材正文禁止进 APK。ChinaTextbook、yuwen、dianzi-keben 仅提供目录和按需打开。教材来源可打开与可用于伴读、缓存或题目引用分别核对。NCR、CKnowEdit 等研究内容禁止进入正式包。详见[第三方内容归因](../ATTRIBUTION.md)。
- 音视频仅走 ECS，示范和数字人朗读采用按需播放；文本按权限下载缓存。详见[媒体约束](../MEDIA_ECS.md)。
- 伴读默认使用已授权的当前读段（短篇段落或电子书当前章/段），麦克风在学生主动发起跟读时申请。私人导入电子书默认保留在个人范围；云端伴读仅上传当前段文本，可一键关闭。埋点使用内容 ID 和事件结果，避免收集全书正文、摘录全文或原始录音。

- 作文原文、草稿和反馈按账号隔离。发起云端批改前告知正文的处理用途，学生可删除草稿和批改记录，作文正文不进入埋点或公开内容。

| 阶段 | 交付 | 发布验收 |
| --- | --- | --- |
| A · 刷题和复习 | 七年级专项题组、错题订正、知识卡入队，保留已有默写和听写 | 跑通选年级 → 做题 → 查看解析 → 错题重做 → 加卡 → 完成一次到期复习 |

| B · 双阅读 + 电子书阅读器 | 课内目录与续读、课外短篇书架、**中文电子书导入与阅读器**（EPUB/TXT 优先）、字词收藏及短篇篇后练习 | 各走通一个课内样本、一个课外短篇、一本自导中文 EPUB/TXT：进度恢复、章节跳转、划词查字、摘录回流；英语 CEFR 书库不作为景行默认首页入口 |
| B+ · 阅读能力与素材 | ① 篇后题标注能力层：至少覆盖「信息提取」「直接推论」两类（可选「理解整合」）② 短篇与电子书摘录一键进入作文素材本（保留书名/篇名、章节或段落定位）③ 低年级可选 10–15 分钟短任务包（字词/朗读），与长专项分流展示 | 七年级样本篇后题带能力标签且可按标签筛选统计。摘录出现在素材本并能量开原文位置。低年级短任务可独立完成并计入当日完成 |
| C · 中文书伴读 | 短篇与电子书阅读器内启动数字人伴读：当前段/章朗读、提示、依据原文提问；弱维出题；TTS 走 ECS | 同一电子书跨两章/两段提问时上下文随位置更新；语音异常后可继续文字伴读与阅读；退出回到原定位。导入书仅发送当前段且可关闭云端伴读 |
| D · 作文 | 七年级记叙文技巧课、片段和整文；写前可从素材本选题意拆解；批改与修改稿对照 | 跑通技巧课 →（可选素材本）→ 练习 → 提交 → 改稿 → 重批；弱网重试与草稿恢复。无素材仍可开写 |
| D+ · 逻辑思辨与议论文 | ① 逻辑思辨微练题包（找论点/补论据/识漏洞/一句反驳）② 八～九年级议论文技巧课与量规 ③ 思辨产出可带入议论文提纲 ④ 综合评估含 `logic_reasoning` | 完成一组思辨微练后，议论文提纲页可见带入的论点/论据。议论文批改能指出论证类问题并链回思辨点。逻辑领域在样本足够时出现在雷达图 |
| 扩展 | 按审核结果补齐年级覆盖；文言、主观题自评、真题与模拟；月度综合练；家长只读周报（可选） | 每个开放年级公布可用题型和读物覆盖，沿用对应学习流程验收 |

**阶段依赖**：A 完成后做 A+；B 完成后做 B+；D 的素材本入口依赖 B+ 摘录能力，若 D 提前启动则先做「空素材本 + 手动粘贴」占位，B+ 落地后改为阅读摘录回流。

每阶段发布前核对年级隔离、账号隔离、重复提交与弱网恢复、内容来源和 APK 资产边界。社区与会员扩展排在核心学习流程之后。

## 7. 竞品审计：叫叫阅读 · JOJOUP · 景行定位

审计目的：对照市面高客单价语文/阅读产品，校验景行 PRD 的取舍，明确「可学的体验与闭环」与「不应复制的商业形态」。

### 7.1 叫叫阅读（约 1800–1980 元年课）在卖什么

叫叫不是「题库 App」，而是 **分阶阅读年课 + 实体书礼盒 + 指导师/社群** 的组合商品。公开产品信息与家长反馈可归纳为：

| 维度 | 叫叫的做法 | 对景行的含义 |
| --- | --- | --- |
| 用户与定价 | 主战场约 3–12 岁；年课约 1800–1980 元，含线上课与按月寄书 | 景行是 K12 **考试向**自学工具，客单价与获客模型不同，不宜对标年课营收结构 |
| 内容组织 | 8 阶能力阶梯：兴趣表达 → 识字习惯 → 自主阅读 → 阅读理解答题 → 古诗文/写作输出 | 景行有年级，但缺「能力阶」与每阶可验收的能力目标；应用内可补「能力标签」，不必做幼教动画阶 |
| 单次学习时长 | 每天约 10–15 分钟短任务，动画互动、IP 陪伴 | 低年级短任务、首页「今日一件事」值得学；动画 IP 非景行核心成本项 |
| 学习闭环 | 「精读、精练、精讲、精测、精评」+ 学豆激励 + 连胜反馈 | 景行已有做题→解析→错题→FSRS；缺 **即时激励、学习报告、能力可视化** |
| 阅读科学化 | 与北师大团队合作儿童中文阅读能力测评（信息提取 / 直接推论 / 理解整合 / 评价鉴赏） | 阅读题与伴读提问可按四层能力出题与统计，增强「会读」而非只「做完题」 |
| 写作 | 「叫叫小作家」：写前素材、写中互动大纲、写后即时点评 | 与景行作文技巧课 + 批改对照高度同向，可强化「意愿—积累—练习」入口 |
| 商业与风险 | 私域转化强；家长侧常见推销、封号/售后争议 | **明确不学**：景行坚持工具型、透明订阅或一次性会员，避免高压私域与预付课陷阱 |

叫叫高阶（约 6–8 阶）已明显贴近校内：答题规范、古诗文意象、读后感/笔记输出——这与景行中高年级路径重叠，景行应在 **证据定位、错题回流、默写听写、考场作文** 上做得更深，而不是再做一套幼教动画课。

### 7.2 JOJOUP（叫叫体系内青少年产品）在卖什么

[JOJOUP](https://jojoup.cn/) 面向青少年文学/语文提分，口号是 **「学 · 练 · 改」三位一体**，更贴近景行用户：

| JOJOUP 能力 | 可借鉴程度 | 景行落地建议 |
| --- | --- | --- |
| 考点 + 解题大招，同步教材 | 高 | 刷题专项每组展示「考点 / 方法」卡片，与知识点 ID 绑定 |
| 即学即练：课课练、天天练、月月练 | 高 | 首页「今日练习」= 到期复习 + 1 组短专项；月度综合卷放扩展阶段 |
| AI 当场改错 + 加题验证 | 高 | 错题订正通过后自动出 1–2 道同知识点验证题（阶段 A 扩展） |
| 智能学习报告（掌握度一览） | 高 | 「我的 / 复习」增加周报：正确率、薄弱知识点、复习完成率 |
| 笔记本（要点归纳） | 中 | 与知识卡合并：从解析一键生成「方法笔记」 |
| 互动视频课 + IP | 中低 | 景行用数字人伴读替代动画课；不做重制作视频课流水线 |
| 班班陪伴服务 | 低（商业模式） | 工具产品不做强督学；可选家长周报推送即可 |

结论：**JOJOUP 的「学练改」比叫叫幼教年课更接近景行；叫叫的「短任务、能力分层、阅读测评维度、即时正反馈」更值得学体验，而非学卖课。**

### 7.3 景行 PRD 对照结论

**已对齐、应坚持**

- 考试向主路径：刷题、错题、FSRS、默写听写、作文批改与版本对照。
- 阅读证据链：解析回原文、伴读按段提问——比叫叫「趣味互动题」更贴应试与深度理解。
- 内容合规：部编正文不进包、媒体走 ECS——竞品年课模式无法也不应照搬。

**PRD 缺口（建议纳入后续版本验收）**

1. **能力模型**：领域雷达（阅读/写作/**逻辑思辨**/文学常识/文言/诗词等）+ 阅读过程技能 + 知识点；综合评估与推题，见 §8。
2. **学练改显式化**：每个专项/技巧课必须能「学方法 → 练母题 → 改错/验证」三步完成，首页用一条任务串起。
3. **即时激励与进度可见**：连胜、当日完成、薄弱点雷达；试点指标已有，产品内缺少学生可见的「我进步了」表面。
4. **低年级短任务包**：10–15 分钟字词/朗读/看图说话，与中高年级长专项分流，避免七年级路径硬套全学段。
5. **写作入口的「意愿」层**：写前素材本/好句库（来自阅读摘录），对齐叫叫小作家与 JOJOUP 积累环节。
6. **议论文前置思辨**：逻辑微练 → 论点论据草稿 → 议论文成文（D+）。
7. **不做**：实体礼盒供应链、高压私域年课转化、以动画课替代题库与错题系统；不做脱离语文语境的纯形式逻辑竞赛题为主路径。

### 7.4 与发布顺序的关系

§6 已将 A+ / B+ 及 D 的素材本增量写入阶段表与勾选清单。竞品结论落到工程上的优先级建议：

1. **先 A+**（学练改可见、验证题、掌握度）——直接抬高刷题留存，不依赖新书库。
2. **再 B+**（阅读能力标签、素材本）——为作文 D 提供积累入口。
3. **D 写前素材** 跟在 B+ 后；若并行，先占位空素材本。

衡量坚持度用工具型指标（短任务完成率、验证通过率、掌握度页打开率），不对标叫叫年课续费率。

## 8. 语文能力画像：多维强弱与综合评估

英语侧靠 CEFR + 词频 + 作答轨迹逐步判断水平。景行用 **「领域雷达 + 过程技能 + 知识点」** 三层结构，识别用户在阅读、写作、文学常识、文言文、诗词等方面的强项与弱项，并给出综合评估与下一步建议。

### 8.1 核心原则：年级 ≠ 能力

| | 英语（AE） | 景行语文 |
| --- | --- | --- |
| 外显档位 | CEFR（A1–C2） | **学段锚点**（声明年级）+ **领域雷达** + 一句话综合评语 |
| 内容标签 | CEFR、词频 | `grade` + `domain` + `knowledge_point` + `reading_skill` + 难度 |
| 记忆层 | 单词/短语 FSRS | 字词、诗句、文言实词、知识点卡 FSRS |
| 推断更新 | 做题、跟读、复习 | 交卷、订正、验证题、篇后题、默写听写、诗文、作文量规 |

声明年级只定 **默认内容池**；真实强弱由行为推断。允许「七年级、现代文阅读强、文言文弱、诗词默写稳」这类错位画像。

### 8.2 三层模型

对每个账号维护 `LearnerProfile`（先本地后云同步）。

#### （1）领域分 `domain_scores`（综合评估主轴）

每个领域维护：`score`（0–100 或 Elo 映射）、`confidence`（有效样本数）、`trend`（近 14 日升降）、`updated_at`。

| domain id | 名称 | 主要证据来源 | 首开学段建议 |
| --- | --- | --- | --- |
| `chars_words` | 字词基础 | 听写、字词专项、新华查词后练习 | 全年级 |
| `modern_reading` | 现代文阅读 | 现代文专项、短篇/电子书篇后题、伴读客观问 | 三～九年级起加重 |
| `writing` | 写作表达 | 片段/整篇量规（记叙四维；议论文含论点/论据/论证/反驳） | 三～九年级起（议论八～九） |
| `logic_reasoning` | 逻辑与思辨 | 找论点、补论据、推理链、识漏洞、反驳/限定微练；议论文阅读篇后思辨题；伴读思辨问 | 七～九年级起（可向下做「观点—理由」轻量） |
| `literary_knowledge` | 文学常识 | 作家作品、体裁流派、文化常识专项/选择题 | 五～九年级起 |
| `classical_prose` | 文言文 | 文言专项、实词虚词、翻译与理解题 | 七～高中（小学仅启蒙可不展示） |
| `poetry` | 诗词曲 | 默写、意象情感、鉴赏题、必背篇目 FSRS | 全年级（低年级偏识记，高年级加鉴赏） |
| `oral_reading` | 朗读表达（可选） | 伴读跟读/朗读完成（后续） | 低年级优先 |

领域分由下属知识点与过程技能 **加权聚合**（见下），不是另起一套互不相关的打分。

#### （2）过程技能（嵌在阅读类领域内）

挂在 `modern_reading` / `classical_prose` / `poetry` 鉴赏下，对齐 PIRLS：

- `extract` 信息提取  
- `infer` 直接推论  
- `integrate` 理解整合  
- `evaluate` 评价鉴赏（高年级）

用于解释「同是现代文阅读，提取尚可、整合偏弱」。

#### （3）知识点 `kp_mastery[kp_id]`

细粒度 Elo/0–1；每条 kp 必须带 `domain`（及可选 `reading_skill`）。专项、错题、验证题、默写篇目都回写到具体 kp，再上卷到领域分。

另保留 **识记巩固 `retention`**：跨领域的 FSRS 稳定性与到期复习完成率，回答「会不会忘」，在综合报告中单列，不替代领域强弱。

### 8.3 强项 / 弱项判定与综合评估

**判定规则（可验收）**

- 仅当 `confidence ≥ N`（建议专项题 ≥ 8 次有效作答，或校准卷覆盖）才标注强/弱；否则显示「待观察」。
- **强项**：该领域分 ≥ 同年级常模 P70（无常模时用绝对阈值如 ≥ 75）且置信足够。  
- **弱项**：≤ P30（或 ≤ 55）且置信足够。  
- **相对强弱**：在用户自己的已测领域内排序，避免「全都偏低」时无相对说法。

**综合评估页（「我的 · 语文能力」）应展示**

1. **雷达图**：已测领域；未测维灰色「待测」。  
2. **一句话总评**：模板生成，例如「现代文阅读与诗词识记较好，文言文实词与写作结构偏弱；建议本周主攻文言验证与记叙文结构短课。」  
3. **Top 弱项 1–3 + 下一步**：各链到今日练习 / 专项 / 伴读 / 技巧课。  
4. **Top 强项 1–2**：鼓励性表述，避免只报忧。  
5. **置信说明**：「基于近 30 天 N 次练习」；样本不足不给武断结论。

综合分可用于排序展示，但 **不得单独作为唯一结论**；报告正文必须落到领域强弱。

```
                      作文量规 → writing

                      伴读提问 → modern_reading 等
                      → 综合评估页与推荐引擎
```

**更新规则**

- 一题可更新：`kp` + 所属 `domain` +（若有）`reading_skill`。  
- 订正通过须经验证题才升 `kp`/领域分。  
- 长期未练维度置信衰减，强/弱标签可退回「待观察」。  
- 推荐优先：**弱项领域 × 低置信或低分 kp**；伴读提问打在阅读弱过程技能上。

**推荐体感**

- 今日练习：到期复习 + 弱项领域短组。  
- 阅读/电子书：篇后题与伴读问法按弱过程技能配比。  
- 作文：量规短板 → 技巧课；素材本可按弱主题倾斜。  
- **议论文**：`logic_reasoning` 弱则先推思辨微练，再推成文；`writing.reasoning` 弱则推论证方法短课。  
- 诗词/文言：弱识记走 FSRS 默写；弱理解走专项与伴读。

### 8.5 与发布阶段挂钩

| 阶段 | 能力评估交付 |
| --- | --- |
| A+ | `kp_mastery` + 初步 `domain` 聚合（至少字词/现代文阅读若有题）；掌握度页列出强弱雏形 |
| B+ | `reading_skill` 入模；现代文阅读可拆过程技能；摘录进素材本 |
| C | 伴读按弱维提问；电子书/短篇作答回写阅读领域 |
| D | `writing` 记叙四维入模；综合评估含写作强弱 |
| D+ | `logic_reasoning` 入模；议论文量规与思辨微练互通；雷达展示逻辑思辨 |
| 扩展 | `literary_knowledge` / `classical_prose` / `poetry` 鉴赏专项标签齐全；冷启动分域短测；月度校准；完整雷达 + 一句话总评 + 家长只读报告 |

**验收（扩展阶段综合评估）**

- [ ] 综合评估页展示不少于 4 个领域的分与置信（有数据的维）  
- [ ] 能指出至少 1 个弱项与 1 个强项（样本足够时），并给出可点击的下一步练习  
- [ ] 题目/默写/作文事件正确写入对应 `domain`；错域不计分  
- [ ] 「待观察」维不出现强/弱徽标  

### 8.6 明确不做

- 不用单一「语文总分」替代领域雷达；不做付费解锁评估。  
- 不把普通话等级当作语文考试能力主轴。  
- 无 `domain` / `reading_skill` 标签的题不硬猜，只更新已标注维度或仅记作答日志。  
- 小学低年级可不展示文言文领域，避免无效焦虑。
